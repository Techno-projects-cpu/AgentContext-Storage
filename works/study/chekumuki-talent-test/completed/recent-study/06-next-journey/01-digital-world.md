# The digital world: how information travels 💻

These are new angles chosen after a text search of the archive, not an official syllabus. Definitions are simplified for school revision.

## Information as bits

1. A **bit** (బిట్) is a binary digit: 0 or 1. Eight bits make one **byte**. These digits can represent many things depending on how software interprets them.
2. In ordinary decimal notation, place values are 1, 10, 100 … . In **binary**, they are 1, 2, 4, 8 … . Thus binary `1011` = 8 + 0 + 2 + 1 = decimal **11**.
3. The same pattern of bits can represent a number, a letter or a pixel: it depends on the **encoding** (సంకేతీకరణ) and context. A bit pattern is not automatically a picture.
4. **Pixel:** a basic picture element in a digital image. More pixels can help capture detail, but lens quality, lighting and compression also matter. Bigger file size alone does not guarantee a better picture.
5. **Lossless compression** can reconstruct the original data exactly; **lossy compression** discards some information to reduce size. Saving an already compressed image repeatedly in a lossy format can reduce quality.

## Instructions, storage and networks

6. An **algorithm (క్రమపద్ధతి)** is a finite set of steps to solve a problem. A recipe is an everyday analogy: inputs are processed according to instructions to produce an output.
7. **Bug:** an error in a program or design. **Debugging** is finding and fixing errors, then checking whether the solution works.
8. **RAM** is working memory used by running programs. It is generally volatile: its contents are lost when power is removed. A storage device such as an SSD is used to retain files when powered off.
9. **CPU** executes instructions; an **input device** such as a keyboard supplies data, and an **output device** such as a display presents results. A touchscreen can do both.
10. **Internet vs web:** the internet is a network of networks; the World Wide Web is a collection of linked resources accessed over the internet. Email and the web are not identical services.
11. **Browser vs search engine:** a browser displays web pages; a search engine helps find pages. A search-result snippet is not proof that a claim is correct.
12. A **packet** is a unit into which data can be divided for transmission. Networks can route packets independently and the receiving system reassembles data as needed.
13. A **URL** is an address for a web resource. Read the domain carefully: a familiar word elsewhere in a long address does not prove the site belongs to that organisation.
14. **Cloud storage** means data is kept on remote computing systems and accessed over a network; it is still stored on physical devices somewhere.

## Safety and critical thinking

15. **Phishing** is an attempt to trick people into revealing information or taking an unsafe action, often through a deceptive message or site. A prize or urgent warning is not proof of authenticity.
16. Do not share passwords, one-time codes or private identity details in response to unsolicited messages. Verify a request through an independently found official contact; ask a trusted adult when unsure.
17. Use a strong unique password for each important account and enable multi-factor authentication when available. A password manager can help. Never post a password as an example.
18. **Encryption** transforms data so that authorised parties with the appropriate key can read it. It protects data in many contexts, but an encrypted connection alone does not prove the website itself is trustworthy.
19. **Backup:** a separate copy of data that can be restored after loss or damage. Check that backups can actually be restored; a single original file is not a backup.
20. **AI output** can sound confident while being wrong. Cross-check factual claims against reliable sources, especially for health, prizes, dates or quotations. Avoid submitting another person's private information without permission.

### Quick check

- Binary `110` = 4 + 2 = **6**.
- A site asks for an OTP to “release your prize”: **do not share it**; independently verify the claim.
- Moving a file to the cloud but deleting every other copy is not necessarily a backup.
