# Connect the pictures: visual quiz practice 🖼️➕🖼️

**Important:** These are text descriptions of possible pictures, not actual images or official JVV slides. Draw them, read them aloud or use suitable labelled textbook images. For real slides an unclear picture or a different set of clues could lead to another sensible answer. Explain how **every clue** fits; don't force a single answer.

## Method

Identify each picture → consider person, place, work, process or category → state a specific link → justify each clue. If one image is ambiguous, ask for clarity rather than inventing details.

## Team drill

A reads three clues; B gives a connection; C explains each clue and proposes an alternative where possible. Rotate roles. Use 1–10 for cultural GK, 11–18 biology, 19–26 physical science and 27–35 mixed. The rounds are practice, not official task descriptions.
