# Fresh picture-connection lab 👁️🧩

These are **descriptions to draw or imagine**, not real photographs or official JVV slides. Each set includes enough labels to practise the intended link; actual images can support different answers. State the shared idea **and explain all three clues**. Cover the right column while answering.

| # | Described pictures | Expected link and reasoning |
|---|---|---|
| 1 | Coloured ink spot + strip of paper in solvent + separated colour bands | **Paper chromatography**: solvent carries components through paper at different rates. |
| 2 | Spinning laboratory tubes + different layers in a tube + centrifuge | **Centrifugation:** spinning helps separate components by settling behaviour; lab staff handle samples. |
| 3 | Cup of soap with poor lather + calcium label + kettle scale | **Hard water:** calcium/magnesium salts can inhibit soap lather and form scale. |
| 4 | Copper label + zinc label + brass key | **Brass:** an alloy mainly of copper and zinc. |
| 5 | Copper label + tin label + bronze bell | **Bronze:** an alloy mainly of copper and tin. |
| 6 | Zinc-coated iron + zinc label + protected railing | **Galvanising:** zinc coating helps protect steel or iron from corrosion. |
| 7 | Barometer + air pressure label + weather map | **Atmospheric pressure:** barometer measures it; maps can show pressure patterns. |
| 8 | Hygrometer + water vapour label + relative humidity reading | **Humidity:** hygrometers measure a humidity quantity, often relative humidity. |
| 9 | Anemometer + moving air + speed reading | **Wind speed:** the anemometer measures it; a vane indicates direction. |
| 10 | Earth cross-section with quake focus + surface point above + seismic waves | **Earthquake focus and epicentre:** origin inside Earth, corresponding point vertically above on the surface. |
| 11 | Seismometer + vibrating ground + squiggly recorded trace | **Seismic recording:** the instrument senses and records ground motion. |
| 12 | Undersea earthquake diagram + ocean-wave series + coastal high ground | **Tsunami:** sudden water displacement can create waves; move to safety according to warnings. |
| 13 | Labelled satellite + field image + crop map | **Remote sensing:** satellite observations can help monitor crops; they need interpretation. |
| 14 | GPS-labelled receiver + several satellites + map position | **Satellite navigation:** signals from multiple satellites help estimate location. |
| 15 | Labelled A antigen + labelled B antigen + red blood cells | **ABO blood-group markers:** the antigens help distinguish A, B, AB and O groups. |
| 16 | Mosquito + label *Plasmodium* + human host | **Malaria transmission:** infected mosquitoes can transmit the parasite. |
| 17 | Legume roots + nodules + nitrogen-fixing bacteria | **Nitrogen fixation / mutualism:** some bacteria in legume root nodules convert nitrogen and receive resources. |
| 18 | Book labelled *Sumati Satakam* + author name బద్దెన + repeated సుమతీ | **Baddena and Sumati Satakam:** the recurring word is a మకుటం. |
| 19 | Book labelled *Dasarathi Satakam* + name కంచర్ల గోపన్న + Bhadrachalam | **Ramadasu / Kancharla Gopanna:** devotional work connected with Rama, not the similarly named modern poet. |
| 20 | Sorted numbers 2, 3, 3, 4, 18 + centre value marked + label మధ్యగతం | **Median:** the middle value is 3. Mean and mode are different concepts. |

**Team tip:** one student names the pictures, one gives the relationship, one checks whether another explanation might also fit. If images lack labels, the same set may be too ambiguous to identify a particular work or author.
