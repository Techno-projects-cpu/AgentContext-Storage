# Connect the pictures: team training 🖼️ + 🖼️ + 🖼️

**These are descriptions, not actual pictures or official slides.** Draw or find the images in school textbooks, label people/places where recognition would otherwise be ambiguous, and cover the answers. Other connections can sometimes be valid: explain how *all* the clues fit.

## Method

1. **Name** each clue; identify anything labelled.
2. Ask if the link is a **person, place, process, category, book or event**.
3. Explain every clue in one sentence; don't stretch a weak clue to fit.
4. If multiple links fit, give the best-supported one or request clarification. Avoid presenting a traditional explanation as settled history.

## Practice like a team

- **Relay:** person A reads clues 1–5; B answers; C checks each link. Rotate every five.
- **Describe, don't guess:** explain two possible links for bee + flower + honey. A connection can be valid without being the one intended.
- **Fair test on paper:** ask whether stirring changes dissolving speed. Compare equal amounts of sugar and water at the same temperature, changing stirring only; measure time and repeat. Do not assume the result. If doing it physically, use teacher supervision; never taste unknown test material.
- **Circuit explanation:** draw a battery, bulb and switch. Explain closed versus open. For physical practice use only an adult-supervised low-voltage kit, never mains electricity or a short circuit.
