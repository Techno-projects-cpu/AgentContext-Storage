# 3. Glossary and Telugu key terms

Telugu glosses are aids, not mandatory official translations. Forms here are for Parliament/Assembly elections and voter registration; check the current form and instructions.

| Term | తెలుగు | Meaning / quiz hook |
|---|---|---|
| Electoral roll | ఓటర్ల జాబితా | Constituency's list of registered electors. |
| Elector | ఓటరు | Eligible person registered in the relevant roll. |
| Constituency | నియోజకవర్గం | Geographic area returning a representative in these direct elections. |
| Delimitation | నియోజకవర్గాల పునర్విభజన | Drawing/readjustment of constituency boundaries and related allocation under law. |
| Nomination | నామినేషన్ | Formal submission to stand for election. |
| Scrutiny | పరిశీలన | RO examines nominations' legal validity. |
| Withdrawal | ఉపసంహరణ | Valid nominee withdraws in the prescribed way by deadline. |
| Security deposit | భద్రతా డిపాజిట్ | Money deposited by candidate; may be forfeited under statutory rule. |
| Polling station | పోలింగ్ కేంద్రం | Place assigned to electors for voting. |
| Presiding Officer | పోలింగ్ కేంద్ర అధ్యక్ష అధికారి | Leads polling at one station. |
| RO / ERO | రిటర్నింగ్ అధికారి / ఓటరు నమోదు అధికారి | RO conducts election; ERO maintains roll. |
| EPIC | ఓటరు గుర్తింపు కార్డు | Electors Photo Identity Card; possession alone does not establish that name is on roll. |
| EVM | ఎలక్ట్రానిక్ ఓటింగ్ యంత్రం | Ballot unit allows choice; control unit records votes. |
| VVPAT | ఓటరు ధృవీకరించదగిన కాగితపు ఆనవాలు | Voter Verifiable Paper Audit Trail; slip is viewed briefly and drops into sealed box. |
| Mock poll | నమూనా పోలింగ్ | Test before actual voting; mock votes cleared. |
| NOTA | పైవారిలో ఎవరూ కాదు | None of the Above; secrecy-protected option, not a candidate. |
| Postal ballot | పోస్టల్ బ్యాలెట్ | Paper voting route for categories eligible under law and notification. |
| Strong room | భద్రపరిచే గది | Secure storage of sealed election equipment after poll. |
| Counting agent | లెక్కింపు ప్రతినిధి | Candidate's authorised representative at counting. |
| Recount | తిరిగి లెక్కింపు | Statutory request and RO decision, not an automatic right after a narrow result. |
| MCC | ఎన్నికల ప్రవర్తనా నియమావళి | Model Code of Conduct, applies during election period. |
| cVIGIL | సి-విజిల్ | Citizen reporting of election violations; 100-minute disposal target is not a legal guarantee. |
| SIR | ప్రత్యేక సమగ్ర సవరణ | Special Intensive Revision of electoral rolls; check current orders, safeguards and deadlines. |
| FPTP | అత్యధిక ఓట్లు పొందిన అభ్యర్థి విజయం | First-past-the-post; most candidate votes wins, not necessarily >50%. |
| By-election | ఉప ఎన్నిక | Election to fill a casual vacancy. |
| Election petition | ఎన్నికల పిటిషన్ | Legal challenge to election as provided by RPA 1951. |

## Forms worth memorising

| Form | Use |
|---|---|
| 6 | Apply for inclusion as a new elector. |
| 6A | Overseas elector registration. |
| 6B | Furnishing Aadhaar information for electoral-roll authentication; enrolment/deletion rules cannot be reduced to a simplistic “no Aadhaar, no vote”. |
| 7 | Objection to proposed inclusion / request deletion of an entry, with grounds and safeguards. |
| 8 | Shifting residence, correction, replacement EPIC or marking disability as applicable. |
| 12D | Application for postal ballot by eligible absentee voters, subject to notification and deadline. |
| 26 | Candidate affidavit with prescribed disclosures. |
| 17A | Register of voters at EVM polling station. |
| 17C Part I | Presiding Officer's account of votes recorded at station; copies to polling agents present. |
| 17C Part II | Result of counting recorded for that station. |
| 20 | Final result sheet consolidating votes, including postal votes. |
| 21C / 21D | Contested general-election / contested casual-vacancy election declaration, respectively. |
| 21E | Return of election. |
| 22 | Certificate of election for returned candidate. |

**Quick contrasts:** announcement ≠ notification; ERO ≠ RO; BLO ≠ BLA; voter register 17A ≠ vote account 17C; a trend ≠ RO declaration; mandatory VVPAT sample ≠ discretionary 56D application; vote share ≠ seats.
