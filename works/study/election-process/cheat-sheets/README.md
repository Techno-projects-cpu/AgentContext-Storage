# Election quiz: four quick cheat sheets

**Don't study everything at once.** Read one sheet, cover it, and explain it aloud. Each sheet is designed for a short revision session.

1. [Election stages](01-election-stages.md) — announcement to winner.
2. [Officials](02-officials.md) — who does what at the voter list, booth and counting centre.
3. [Laws and numbers](03-laws-and-numbers.md) — the most useful articles, laws and figures.
4. [Voting and counting](04-voting-counting.md) — EVM, VVPAT, forms and the winner.

**Scope:** Direct Lok Sabha and State Assembly elections. English with a few Telugu terms. This is a quick revision aid, not the full set of rules. For details, sources and current affairs see the [full study pack](../README.md). Laws and election instructions can change; check the latest ECI directions.
